# git-gyakorlo-01

## Feladat

1. Fork-old le ezt a repót a saját GitHub-fiókodba (jobb felül, **Fork** gomb).
2. Klónozd le VS Code-ban a SAJÁT fork-odat (ne az eredetit!):

git clone https://github.com/<a-te-github-felhasznalonev>/git-gyakorlo-01

3. Hozz létre egy `valasz.txt` fájlt a repó gyökerében, benne egy mondattal: mit tanultál ma az órán.
4. Mentsd el a változtatást:

git add .
git commit -m "valasz.txt hozzáadva"
git push

5. Nyiss egy Pull Requestet a saját fork-odból, ide, az eredeti repóba.
